# ITP_SE_Team12: AI-Driven Golf Swing Analytics System

## Project description
The objective of this project is to develop a Proof-of-Concept AI model using Computer Vision to identify key body parts and analyze golf swings from video footage. Additionally, the project involves creating a Front-End coaching feedback system. This system will provide golfers with detailed assessments of their swings, comparing them against established benchmarks of good swing mechanics. The ultimate goal is to help golfers improve their performance through data-driven insights.

To further support real-time analysis and improve usability, external peripherals has been integrated into the system for automatic video recording using pose detection.

## Scope

#### Live Video Recording
- Integration of external peripherals to automate swing recording.

#### Video Analysis
- Utilize golf swing videos to identify relevant body parts that are crucial to golf swing movements.

#### Data Extraction
- Overlay a stick figure on the videos to extract frame-by-frame posture changes.
- Gather data on positions and angles for detailed analysis.

#### Dataset Creation
- Compile data from hundreds/thousands of textbook swings to establish benchmarks for good swing characteristics.
- Define and labelled ground truth for each swing position.

#### AI Model Training
- Develop a pre-trained model that can assess and categorize new swings based on learned parameters.
- Apply machine techniques such as cross-validation and hyperparameter tuning to improve model robustness.

#### Keywords
AI, Data Analysis, Model Training, Pose Estimation, Real-time Feedback

## Final deliverable(s)
- Curated dataset used for training and evaluation of the AI model.
- Front-end coaching feedback system for user interaction.
- Live video recording that allows user to record directly via the platform.
- Enhanced AI model capable of identifying key body parts and analyzing golf swings from videos.
